# 아큐브 웹 AR 마이크로사이트 기술 제안 및 구축 계획서

## 1. 프로젝트 개요
- **목적**: 콘택트 렌즈(다초점 등) 착용 경험을 사전 체험하도록 돕는 모바일 퍼스트 AR 마이크로사이트 구축
- **핵심 요구사항**:
  - 얼굴/눈/홍채 실시간 추적 (Face & Iris Tracking)
  - 셀프 카메라를 활용한 렌즈 착용 전/후 2D 그래픽 시뮬레이션
  - 눈 영역 제외 실시간 블러(Blur) 처리 (실감 나는 초점 효과)
  - 눈 주변 SF 영화 스타일의 HUD 및 포커싱 애니메이션
- **제약 사항**: 상용 AR/얼굴 인식 프레임워크(월 구독료/트래픽 기반 과금 등) 배제, **100% 무료 오픈소스 생태계** 기반으로 구현

---

## 2. 최적의 무료 오픈소스 프론트엔드 기술 스택 제안

### 2.1. 프론트엔드 코어 (Frontend Core)
- **기술**: **React + Vite**
- **선택 이유**:
  - 특정 서버리스 플랫폼(Vercel, Netlify 등)의 상업적 제약 및 트래픽 요금제에 종속되지 않고 빌드된 정적(static) 파일만으로 어떤 호스팅 환경에서든 100% 무료 및 최소 비용으로 서비스가 가능합니다.
  - 상태 관리 및 모바일 퍼스트 UI 컴포넌트 생태계가 가장 풍부합니다.
- **스타일링**: **Tailwind CSS + Framer Motion**
  - 가벼운 모바일 최적화 스타일링과 즉각적이고 부드러운 UI 전환 애니메이션(안내문구, 버튼, 전환 효과) 적용에 최적입니다.

### 2.2. 모션 및 얼굴/눈 추적 엔진 (Face & Iris Tracking)
- **기술**: **Google MediaPipe (Face Landmark Detection)**
- **선택 이유**:
  - **100% 무료, 오픈소스(Apache-2.0)**입니다.
  - 브라우저 상에서 WebAssembly(WASM) 및 WebGL을 통해 별도 서버 통신 없이 디바이스의 리소스만으로 빠르고 가볍게 구동됩니다.
  - 눈과 홍채(Iris) 등 478개의 얼굴 랜드마크를 고해상도로 추적할 수 있어 다초점 렌즈 합성에 필수적인 정밀한 눈동자 위치 및 크기 계산이 가능합니다.

### 2.3. 그래픽 및 실시간 렌더링 (Graphics & Shaders)
- **기술**: **Three.js + Custom WebGL Shader** (또는 PixiJS)
- **선택 이유**:
  - "눈 영역을 제외한 나머지 화면 전체의 실시간 블러 처리"는 일반적인 CSS로는 동적 마스킹 등 모바일 기기의 브라우저에서 성능 한계(프레임 저하)가 큽니다.
  - Three.js를 사용해 카메라 스트림 자체를 WebGL 텍스처로 올리고, MediaPipe에서 추출한 두 눈의 좌표를 Fragment Shader로 넘겨, **눈에서 멀어지는 픽셀에만 연산 기반의 Gaussian Blur를 먹이는 방식**으로 구현하면 모바일 환경(Safari/Chrome)에서도 60fps에 가까운 실시간 효과를 만들 수 있습니다.

### 2.4. SF HUD 파티클 및 애니메이션 (SF UI/UX)
- **기술**: **HTML5 Canvas / SVG Animations + GSAP (또는 Framer Motion)**
- **선택 이유**:
  - MediaPipe에서 계산된 눈 주변 좌표(x, y)에 맞춰 SVG 스캐닝 링, 십자선(Crosshair), HUD 프레임 박스 위치를 동적으로 업데이트합니다.
  - 렌즈 초점을 잡는 순간 SVG Path 애니메이션(선이 그려지며 락온(Lock-on)되는 등)을 통해 SF적 감성을 극대화할 수 있습니다.

## 3. 기능 구현 상세 솔루션

1. **2D 렌즈 시뮬레이션 합성**
   - MediaPipe를 통해 사용자가 눈을 떴을 때, 윗 눈꺼풀과 아랫 눈꺼풀, 그리고 눈동자 중앙 좌표를 구합니다.
   - 얻은 위치와 거리 정보(스케일)에 기반해 준비된 2D 렌즈 에셋(투명 PNG)을 Canvas에 WebGL Overlay로 맵핑시킵니다.
   - 사용자의 머리 회전에 맞춰 렌즈 그래픽 또한 원근감(Perspective)을 적용합니다.

2. **다초점 렌즈 체험 (실시간 부분 블러 적용 방식)**
   - 평소 시력(블러 상태): 렌즈 착용 전에는 화면 전체를 흐릿하게(Uniform Blur) 보여줍니다.
   - 초점 맞추기(SF HUD 등장): 얼굴을 인식하여 눈동자에 락온 타겟팅 스캐닝이 돌아가고 효과음(옵션)이 발생합니다.
   - 렌즈 착용 후(Focusing 매직): 눈동자 주의(Center)의 일정 반경(Radius) 안의 픽셀들부터 바깥쪽으로 그라데이션 블러 처리를 풀며, 초점이 맞는 부분을 선명하게 만듭니다. (커스텀 쉐이딩 효과)

## 4. 단계별 개발 마일스톤 (액션 플랜)

### Phase 1: 개발 환경 및 프로토타이핑 세팅 (1~2주)
- 모바일 프론트엔드 보일러플레이트 구축 (React + Vite)
- 모바일 디바이스 웹 브라우저의 카메라 권한 요청 및 비디오 스트리밍 캡처 테스트
- MediaPipe Face Landmark 라이브러리 연동 및 초당 프레임(FPS), 눈 위치 좌표 반환 테스트 도구 제작

### Phase 2: 코어 AR 및 렌더링 구현 (2~3주)
- Three.js WebGL 환경 구성 및 카메라 비디오 원소스를 Plane 텍스처로 로딩
- Custom Fragment Shader 작성: 눈동자 좌표를 넘겨 받아 마스킹 및 실시간 그라데이션 블러(Masking Gradient Blur) 이펙트 완벽 구현
- 눈동자 크기(스케일링 적용)에 비례하여 2D 렌즈 텍스처 정확한 뎁스와 위치에 합성

### Phase 3: 애니메이션 및 SF HUD UI/UX 개발 (1~2주)
- 사용자의 시선과 눈 좌표를 따라다니는 스캐닝 HUD, 가이드 십자선 UI 제작
- 앱 진입 → 카메라 허용 → 얼굴 스캔 → 렌즈 시연으로 이어지는 인터랙션 및 화면 전환 애니메이션(Framer Motion) 반영
- 착용 전/후 전환 토글(슬라이더 바 형식 구현 등) 인터페이스 생성

### Phase 4: 성능 최적화 및 안정화 (1~2주)
- iOS Safari 및 Android Chrome 다양한 단말기에서의 호환성 테스트
- 얼굴 인식 연산을 Web Worker로 분리시켜 메인 스레드 렌더링 성능(초당 프레임) 향상 및 Jitter(떨림) 현상을 잡기 위한 보간(Lerp/Kalman Filter) 스무딩 알고리즘 적용
- 최종 산출물 GitHub 등 무료 호스팅 오픈소스 배포 테스트
